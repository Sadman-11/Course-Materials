## 📁 Repository Structure

The repository is organized by **Course Code** and **Instructor Name**. Each course folder typically contains:

```
CourseCode/
├── InstructorName/
│   ├── Lecture/
│   ├── Lab/
│   ├── Practice_Problems/
│   ├── Lecture_PDF/ or Lecture_Slides/
│   ├── Questions/
│   ├── Project/
│   ├── Books/
│   └── EXAM/
```

## 🤝 Contributing

We welcome contributions from instructors, students, and alumni! If you have course materials, lecture notes, practice problems, or exam papers you'd like to share, please consider contributing to this repository.

### How to Contribute

1. **Add Your Materials**: 
   - Create or navigate to the appropriate course and instructor folder
   - Add your materials in the relevant subdirectory (Lecture, Lab, Practice_Problems, etc.)

2. **Follow the Structure**: 
   - Maintain the existing folder structure for consistency
   - Organize materials logically (e.g., Lecture slides in `/Lecture`, labs in `/Lab`)

3. **Provide Clear Documentation**:
   - Include file names that describe the content
   - Add any necessary instructions or notes

4. **Submit Your Contribution**:
   - Create a pull request with a clear description of your additions
   - Include the course code, instructor name, and brief description of materials

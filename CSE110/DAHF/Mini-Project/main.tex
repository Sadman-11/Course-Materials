\section{Introduction}
%==============================================================================

The \textbf{Smart Task Manager} is an interactive console-based Java application designed to help users organize and manage their daily tasks efficiently. The application allows users to create, track, and manage both personal and work-related tasks through a user-friendly menu-driven interface.

\subsection{Motivation and Purpose}

The motivation behind creating this application was to develop a practical task management tool that demonstrates core Object-Oriented Programming (OOP) concepts while providing real utility. The application helps users stay organized by categorizing tasks, tracking completion status, and persisting data between sessions.

\subsection{Main Features}

\begin{itemize}
    \item \textbf{Add Tasks}: Create new work or personal tasks with titles and descriptions
    \item \textbf{Mark Completion}: Mark tasks as completed with status tracking
    \item \textbf{View Tasks}: Display all tasks, completed tasks only, or pending tasks only
    \item \textbf{Data Persistence}: Save and load tasks from file for data retention
    \item \textbf{Interactive Menu}: User-friendly console interface with visual formatting
\end{itemize}

\subsection{OOP Concepts Demonstrated}

\begin{itemize}
    \item \textbf{Class and Object}: Multiple classes representing different entities (Task, WorkTask, PersonalTask, TaskManager)
    \item \textbf{Encapsulation}: Private fields with public getter/setter methods
    \item \textbf{Inheritance}: WorkTask and PersonalTask extending the abstract Task class
    \item \textbf{Polymorphism}: Overridden methods providing different behaviors in subclasses
    \item \textbf{Exception Handling}: Custom TaskNotFoundException and try-catch blocks
\end{itemize}

\section{System Design}
%==============================================================================

\subsection{Overview of the System Structure}

The Smart Task Manager follows a hierarchical class structure with clear separation of concerns:

\begin{verbatim}
TaskManager (Main Application)
    |
    +-- Task (Abstract Base Class)
    |       |
    |       +-- WorkTask (Subclass)
    |       |
    |       +-- PersonalTask (Subclass)
    |
    +-- TaskNotFoundException (Custom Exception)
\end{verbatim}

\subsection{Program Flow (Start to End)}

\begin{enumerate}
    \item \textbf{Startup}: \texttt{TaskManager.main()} creates a TaskManager instance
    \item \textbf{Load Data}: \texttt{loadTasksFromFile()} loads any previously saved tasks
    \item \textbf{Display Welcome}: Shows welcome banner to user
    \item \textbf{Main Loop}: Displays menu and processes user choices
    \item \textbf{User Operations}: Add tasks, mark completed, view tasks, etc.
    \item \textbf{Save \& Exit}: Saves tasks to file and exits gracefully
\end{enumerate}

\subsection{Encapsulation}
%------------------------------------------------------------------------------
\textbf{Example from Task class:}

\begin{lstlisting}[caption={Encapsulation in Task Class}]
// Private fields - cannot be accessed directly from outside
private int id;
private String title;
private String description;
private boolean isCompleted;

// Public getters - provide read access
public int getId() { return id; }
public String getTitle() { return title; }

// Public setters - provide write access with potential validation
public void setTitle(String title) { this.title = title; }
public void setCompleted(boolean completed) { 
    this.isCompleted = completed; 
}
\end{lstlisting}
\newpage
\textbf{Benefits of Encapsulation Used:}
\begin{enumerate}
    \item \textbf{Data Protection}: External code cannot directly modify internal state
    \item \textbf{Validation Opportunity}: Setters can validate input before assignment
    \item \textbf{Implementation Flexibility}: Internal representation can change without affecting external code
    \item \textbf{ID Management}: The \texttt{id} field has no setter, ensuring IDs remain unique and immutable
\end{enumerate}

\subsection{Important Code Snippets}

\subsubsection{Constructor Example (Task.java)}

\begin{lstlisting}[caption={Task Constructor}]
public Task(String title, String description) {
    this.id = idCounter++;           // Auto-generate unique ID
    this.title = title;
    this.description = description;
    this.isCompleted = false;        // New tasks start as incomplete
}
\end{lstlisting}

\textit{This constructor demonstrates encapsulation by initializing private fields and using a static counter for automatic ID generation.}

\subsubsection{Overridden Method Example (WorkTask.java)}

\begin{lstlisting}[caption={WorkTask getDetails() Method}]
@Override
public String getDetails() {
    String status = isCompleted() ? "Completed" : "Pending";
    return String.format(
        "[WORK TASK] ID: %d\n" +
        "Title: %s\n" +
        "Description: %s\n" +
        "Status: %s",
        getId(), truncate(getTitle(), 32),
        truncate(getDescription(), 27), status
    );
}
\end{lstlisting}

\textit{This method overrides the abstract \texttt{getDetails()} from Task class, demonstrating polymorphism. Each subclass provides its own unique formatting.}
\newpage
\subsubsection{Try-Catch Block Example (TaskManager.java)}

\begin{lstlisting}[caption={Exception Handling Example}]
try {
    String indexInput = scanner.nextLine().trim();
    int index = Integer.parseInt(indexInput);
    
    // Validate index and throw custom exception if invalid
    validateTaskIndex(index);
    
    Task task = tasks.get(index);
    task.setCompleted(true);
    System.out.println("\nTask marked as completed!");
    
} catch (NumberFormatException e) {
    System.out.println("\nInvalid input! Please enter a valid number.");
} catch (TaskNotFoundException e) {
    System.out.println("\nError: " + e.getMessage());
}
\end{lstlisting}

\textit{This demonstrates exception handling with multiple catch blocks for different exception types.}

\subsubsection{Custom Exception Class (TaskNotFoundException.java)}

\begin{lstlisting}[caption={Custom Exception Class}]
public class TaskNotFoundException extends Exception {
    public TaskNotFoundException(String message) {
        super(message);
    }
    
    public TaskNotFoundException(int index, int maxIndex) {
        super("Task not found at index " + index + 
              ". Valid range: 0 to " + maxIndex);
    }
}
\end{lstlisting}

\textit{Custom exception providing meaningful error messages for invalid task access attempts.}

\section{Conclusion}
%==============================================================================

\subsection{Project Achievements}

The Smart Task Manager successfully implements a functional task management application that allows users to create, track, and manage tasks through an intuitive console interface. The application demonstrates proper use of Object-Oriented Programming principles including encapsulation, inheritance, polymorphism, and exception handling.

\subsection{OOP Concepts Learned}

Through this project, the following OOP concepts were practically applied:

\begin{itemize}
    \item \textbf{Encapsulation}: Using private fields with public accessors protects data integrity
    \item \textbf{Inheritance}: Creating specialized task types (WorkTask, PersonalTask) from a common base class promotes code reuse
    \item \textbf{Polymorphism}: Storing different task types in a single collection and calling overridden methods enables flexible, extensible code
    \item \textbf{Abstraction}: The abstract Task class defines a contract that subclasses must fulfill
    \item \textbf{Exception Handling}: Custom exceptions and try-catch blocks make the application robust and user-friendly
\end{itemize}

\subsection{Future Enhancements}

Potential improvements for future versions:

\begin{enumerate}
    \item \textbf{Priority Levels}: Add high/medium/low priority to tasks
    \item \textbf{Due Dates}: Add deadline tracking with reminder functionality
    \item \textbf{Task Categories}: Allow custom categories beyond Work/Personal
    \item \textbf{Search Functionality}: Search tasks by keyword or filter by various criteria
    \item \textbf{GUI Interface}: Develop a graphical user interface using JavaFX or Swing
    \item \textbf{Database Storage}: Replace file storage with SQLite or MySQL database
    \item \textbf{Task Editing}: Allow modification of existing task titles and descriptions
    \item \textbf{Task Deletion}: Add ability to remove tasks from the list
    \item \textbf{Statistics Dashboard}: Show completion rates and productivity metrics
    \item \textbf{Export Options}: Export tasks to PDF or CSV format
\end{enumerate}
